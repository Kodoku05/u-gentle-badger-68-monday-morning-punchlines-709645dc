# Monday Morning Punchlines

A deadpan HR séance turns an employee's escape from a Monday morning meeting into one last training assignment.

## Run it

```sh
node main.ts
```

Writes the joke to `/output/entry.txt`, or to `entry.txt` in `MAKEFUN_OUTPUT_DIR` when set, without a trailing newline.
